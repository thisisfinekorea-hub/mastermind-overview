# 공개 범위

## 공개한 내용

- 시스템의 목적과 주요 앱의 역할
- 선별한 폴더 이름과 개념적인 구성
- 주요 업무 흐름과 데이터 소유 관계
- 일반적인 기술 구성

## 공개하지 않은 내용

- 가격, 단가, 원가, 급여, 매출액, 손익, 예산과 정산 내역
- 금액을 역산할 수 있는 실제 거래 내역과 수량 자료
- 고객·직원·거래처 개인정보와 연락처
- 계약서, 발주서, 재무 문서와 내부 보고서
- 운영 DB, 주문 파일, 재고 기록과 원본 이미지
- 운영 소스 코드와 내부 Git 이력
- 계정, 비밀번호, API 키, 토큰과 인증 설정
- 운영 서비스 주소, 내부 호스트와 배포 설정
- 실제 내부 업무 기록과 인계 문서

## 공개 방식

이 저장소는 허용한 설명 문서만 새로 작성해 구성했습니다.
내부 저장소를 공개로 전환하거나 일부 파일만 숨겨 공개하는 방식이 아닙니다.
공개본에는 로그인 기능과 금액 데이터가 없으며, 내부 자료를 불러오는 연동도 없습니다.

추가 공개가 필요하면 공개할 문서를 따로 작성하고 내용을 검토한 뒤 반영합니다.
