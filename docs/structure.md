# 주요 폴더와 앱의 역할

실제 내부 구성에서 주요 영역을 선별한 설명입니다. 전체 파일 목록이나 실행 가능한 프로젝트 사본은 아닙니다.
금액을 처리하는 앱의 구현과 데이터는 이 안내에서 제외합니다.

| 내부 주요 경로 | 역할 |
|---|---|
| `0_hub/` | 통합 업무 진입점, 업무 보드와 앱 탐색 |
| `3_barcode/` | Production: 상품·옵션·바코드와 생산 차수·생산 이벤트 관리 |
| `25_spec/` | 상품 치수, 소재, 라벨링과 상품 설명 관리 |
| `29_workorder/` | 작업지시서와 생산 지시 문서 구성 |
| `30_studio/` | 쇼룸 실사, 입고 검수와 현장 콘텐츠 업무 |
| `32_shipping/` | 주문 출고, 송장 처리, 물류 재고 조회와 CS 업무 |
| `16_calendar/` | 일반 일정과 생산 일정 표시 |
| `31_meeting/` | 팀 보고, 회의록과 후속 실행 관리 |
| `17_gallery/` | 착용 이미지와 상품 연결 관리 |
| `28_moments/` | 선별 이미지의 쇼룸 전시 |
| `19_tif-direct/` | 자사몰 운영 관련 작업과 자료 |
| `20_blog-seo/` | 브랜드 블로그와 검색 콘텐츠 작업 |
| `8_content-auto/` | 콘텐츠 생성 보조 |
| `9_nukki-auto/` | 이미지 배경 제거 작업 보조 |
| `22_seeding/` | 협찬 업무 관리 |
| `34_gacha/`, `35_letter/` | 브랜드 이벤트 기능 |
| `6_webapp-design/` | 공통 디자인 기준 |
| `shared/` | 공통 UI와 재사용 기능 |
| `memory/` | 내부 업무 규칙, 결정과 인계의 관리 영역 |
| `documents/` | 업무별 문서와 산출물의 관리 영역 |

경로 이름은 역할을 설명하기 위한 표기입니다. 이 저장소에 해당 운영 폴더나 그 내용을 복사하지 않았습니다.
`memory/`와 `documents/`의 실제 내부 문서는 공개 대상에 포함하지 않습니다.

## 앱을 나누는 기준

중앙 Hub에서 업무에 진입하고, 기능별 앱이 자기 업무의 입력과 처리를 담당합니다.
공통 UI와 탐색 기능을 공유하며, 상품 기준을 여러 앱에서 참조해 중복 입력을 줄입니다.
앱의 규모에 따라 서버, 데이터 처리, UI 또는 기능별 폴더로 구성을 나눕니다.
